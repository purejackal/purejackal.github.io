당신은 일본 콘텐츠 SEO 전문가입니다.
아래 와비사비 심리 드라마 대본을 기반으로 YouTube/블로그용 SEO 최적화 메타데이터를 생성하세요.

═══════════════════════════════════════════════════════════
🎯 SEO 생성 목표
═══════════════════════════════════════════════════════════

• 일본 시니어층(50대~60대) 타겟
• 감성적이면서도 검색 친화적
• 와비사비, 심리 드라마 키워드 포함
• YouTube 및 Google 검색 최적화

═══════════════════════════════════════════════════════════
📋 생성할 항목
═══════════════════════════════════════════════════════════

1. 메인 제목 (Title)
   - 길이: 40~60자
   - 감성적이면서 클릭을 유도
   - 핵심 키워드 포함
   - 예: "고요한 복수 | 60세, 그녀가 선택한 마지막 자존심 [와비사비 드라마]"

2. 부제목 (Subtitle)
   - 길이: 30~50자
   - 메인 제목 보완
   - 감정선 강조

3. 짧은 설명 (Short Description)
   - 길이: 100~150자
   - 스토리 핵심 요약
   - 감정적 훅 포함

4. 전체 설명 (Full Description)
   - 길이: 300~500자
   - 스토리 개요
   - 감정적 포인트
   - 대상 독자층 명시
   - CTA (Call-to-Action) 포함

5. 태그 (Tags)
   - 개수: 15~20개
   - 일본어/한국어 혼용
   - 카테고리별 분류:
     * 장르: 심리드라마, 와비사비, 인생드라마
     * 감정: 고독, 복수, 해방, 인과응보
     * 대상: 시니어, 50대, 60대
     * 스타일: 정적, 절제, 감성

6. 키워드 (Keywords)
   - 검색 최적화용 5~7개
   - 롱테일 키워드 포함

7. 해시태그 (Hashtags)
   - SNS용 5~8개
   - # 포함

═══════════════════════════════════════════════════════════
✍️ 작성 가이드라인
═══════════════════════════════════════════════════════════

【문체】
  • 정중하고 품위 있는 표현
  • 과장 금지
  • 감성적이되 절제된 톤
  • 시니어 공감 표현

【키워드 전략】
  • 핵심 키워드: 와비사비, 심리드라마, 인생드라마
  • 감정 키워드: 고독, 복수, 해방, 인과응보
  • 타겟 키워드: 시니어, 50대, 60대
  • 스타일 키워드: 정적, 절제, 일본풍

【SEO 최적화】
  • 제목 앞부분에 핵심 키워드 배치
  • 자연스러운 키워드 밀도 유지
  • 감정적 훅 + 정보 제공 균형
  • 검색 의도 반영
