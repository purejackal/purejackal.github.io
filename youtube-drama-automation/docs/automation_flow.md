# 🔄 자동화 플로우 상세 설명

YouTube → 와비사비 드라마 자동화의 전체 흐름을 단계별로 설명합니다.

## 📊 전체 플로우 다이어그램

```
┌─────────────────┐
│ Google Sheets   │
│ (대기중 URL)    │
└────────┬────────┘
         │
         ▼
┌─────────────────┐
│ YouTube         │
│ Transcript API  │ ← RAW 대본 추출
└────────┬────────┘
         │
         ▼
┌─────────────────┐
│ LLM 각색        │
│ (와비사비)      │ ← 심리 드라마로 재창작
└────────┬────────┘
         │
         ▼
┌─────────────────┐
│ LLM SEO 생성    │
│ (메타데이터)    │ ← 제목, 태그, 설명 생성
└────────┬────────┘
         │
         ▼
┌─────────────────┐
│ JSON 파싱       │
│ (구조화)        │ ← SEO 데이터 구조화
└────────┬────────┘
         │
         ▼
┌─────────────────┐
│ Google Sheets   │
│ (완성 저장)     │ ← 모든 데이터 저장
└────────┬────────┘
         │
         ▼
┌─────────────────┐
│ Telegram 알림   │
│ (선택사항)      │ ← 완료 알림
└─────────────────┘
```

## 🎯 단계별 상세 설명

### 단계 1: 대기 URL 검색

**모듈**: Google Sheets - Search Rows

**동작**:
- `대기중_영상` 시트에서 `status = '대기중'` 조건의 행 검색
- 발견된 각 행에 대해 후속 모듈 실행

**출력**:
```json
{
  "row_id": 1,
  "youtube_url": "https://www.youtube.com/watch?v=example",
  "status": "대기중",
  "added_at": "2025-11-23 10:00:00",
  "notes": "테스트"
}
```

**에러 처리**:
- 대기 중인 URL이 없으면 시나리오 종료
- 잘못된 시트 이름이면 오류 로그 기록

---

### 단계 2: YouTube 대본 추출

**모듈**: HTTP - Make a Request

**동작**:
- YouTube Transcript API에 POST 요청
- 영상 URL을 video_id로 변환
- 자막/대본 텍스트 추출

**요청 예시**:
```json
{
  "video_url": "https://www.youtube.com/watch?v=example",
  "language": "ja",
  "format": "text"
}
```

**응답 예시**:
```json
{
  "video_id": "example",
  "title": "영상 제목",
  "transcript": "오늘은 제 친구 이야기를...",
  "language": "ja",
  "duration": 300,
  "word_count": 1500
}
```

**에러 처리**:
- **No transcript**: 오류_로그 시트에 기록, 다음 URL 처리
- **Private video**: 오류_로그 기록
- **API limit**: 60초 대기 후 재시도 (최대 3회)

**처리 시간**: 약 2~5초

---

### 단계 3: 와비사비 스타일 각색

**모듈**: OpenAI - Create Completion

**동작**:
- RAW 대본을 LLM에 입력
- 와비사비 프롬프트로 각색 지시
- 커스텀 태그 포함된 드라마 대본 생성

**프롬프트 구조**:
```
System: [wabisabi_script_prompt.txt 전체 내용]
User: [2단계에서 추출한 RAW 대본]
```

**LLM 설정**:
```json
{
  "model": "gpt-4",
  "temperature": 0.7,
  "max_tokens": 3000,
  "top_p": 1
}
```

**출력 예시**:
```
제목: 해방의 그림자 | 30년이 남긴 고요
테마: 고요한 해방

[SCENE: 석양_지는_사무실]
[AUDIO_CUE: 먼_자동차_소리]
"30년."
[TTS_TAG: 무감정_90]
...
```

**에러 처리**:
- **Rate limit**: 60초 대기 후 재시도
- **Invalid response**: 오류 로그 기록 후 스킵
- **Timeout**: 타임아웃 120초로 설정

**처리 시간**: 약 20~40초 (GPT-4 기준)

**비용**: 약 $0.03~0.05 per request (GPT-4)

---

### 단계 4: SEO 메타데이터 생성

**모듈**: OpenAI - Create Completion

**동작**:
- 각색된 와비사비 대본을 분석
- SEO 최적화 제목, 설명, 태그 생성
- JSON 형식으로 출력

**프롬프트 구조**:
```
System: [seo_generation_prompt.txt 전체 내용]
User: [3단계에서 생성된 와비사비 대본]
```

**LLM 설정**:
```json
{
  "model": "gpt-4",
  "temperature": 0.5,
  "max_tokens": 1500
}
```

**출력 예시**:
```json
{
  "title": "고요한 복수 | 60세, 그녀가 선택한 마지막 자존심",
  "subtitle": "30년의 인내 끝에 찾은 진짜 자유",
  "short_description": "회사에서 해고당한 56세 미즈키. 30년의 굴레에서 벗어나...",
  "full_description": "30년간 한 우물을 판 미즈키는 어느 날...",
  "tags": ["와비사비", "심리드라마", "고독", "해방", "시니어"],
  "keywords": ["일본 드라마", "와비사비 스토리", "50대 인생"],
  "hashtags": ["#와비사비", "#심리드라마", "#고요한해방"],
  "category": "심리드라마/와비사비",
  "target_audience": "일본 시니어층 (50대~60대)",
  "emotional_hook": "30년의 억압에서 벗어난 고요한 자유"
}
```

**에러 처리**:
- **JSON 형식 오류**: 재시도 1회
- **Rate limit**: 60초 대기
- **빈 응답**: 오류 로그 기록

**처리 시간**: 약 10~20초

**비용**: 약 $0.02~0.03 per request (GPT-4)

---

### 단계 5: JSON 파싱

**모듈**: JSON - Parse JSON

**동작**:
- LLM 응답을 JSON 객체로 변환
- 각 필드를 개별 변수로 추출
- Google Sheets 저장을 위한 준비

**입력**:
```
{{4.choices[0].message.content}}
```

**출력**:
```
5.title → "고요한 복수 | 60세, 그녀가..."
5.subtitle → "30년의 인내 끝에..."
5.tags → ["와비사비", "심리드라마", ...]
...
```

**에러 처리**:
- **Invalid JSON**: 오류 로그 기록
- **누락된 필드**: 기본값 사용 또는 null

**처리 시간**: 1초 미만

---

### 단계 6: Google Sheets 저장

**모듈**: Google Sheets - Update a Row

**동작**:
- `완성_대본` 시트에 새 행 추가
- 모든 데이터를 구조화하여 저장
- 상태를 '완료'로 업데이트

**저장 데이터**:
```
row_id: 1
youtube_url: https://www.youtube.com/watch?v=example
raw_transcript: [원본 대본]
wabisabi_script: [각색 대본]
title: [SEO 제목]
subtitle: [부제목]
short_description: [짧은 설명]
full_description: [전체 설명]
tags: 와비사비, 심리드라마, 고독, ...
keywords: 일본 드라마, 와비사비 스토리, ...
hashtags: #와비사비 #심리드라마 #고요한해방
category: 심리드라마/와비사비
target_audience: 일본 시니어층 (50대~60대)
emotional_hook: 30년의 억압에서 벗어난 고요한 자유
status: 완료
created_at: 2025-11-23 15:30:00
```

**에러 처리**:
- **권한 오류**: 연결 재인증 필요
- **시트 없음**: 오류 로그 기록
- **데이터 형식 오류**: 텍스트로 변환 후 저장

**처리 시간**: 약 2~3초

---

### 단계 7: Telegram 알림 (선택)

**모듈**: Telegram - Send a Message

**동작**:
- 완료 알림을 Telegram 채팅방에 전송
- 제목, 카테고리, 상태 요약

**메시지 예시**:
```
✅ 새로운 와비사비 드라마 완성!

제목: 고요한 복수 | 60세, 그녀가 선택한 마지막 자존심
카테고리: 심리드라마/와비사비
상태: 완료
완성 시간: 2025-11-23 15:30:00
```

**처리 시간**: 1초 미만

## 🔁 배치 처리

여러 URL을 한 번에 처리하려면:

1. `대기중_영상` 시트에 여러 URL 입력
2. 모든 행의 status를 '대기중'으로 설정
3. Make.com 시나리오가 자동으로 순차 처리
4. 각 URL당 약 60~80초 소요

**예시**:
- 10개 URL → 약 10~15분
- 50개 URL → 약 50~70분

## 📊 모니터링

### Make.com에서 확인
- 시나리오 실행 기록
- 각 모듈별 성공/실패
- 에러 로그

### Google Sheets에서 확인
- `완성_대본`: 성공적으로 처리된 항목
- `오류_로그`: 실패한 항목 및 원인

---

## 🛡️ 에러 처리 전략

### 자동 재시도
- API Rate Limit: 60초 대기 후 재시도 (최대 3회)
- Timeout: 타임아웃 연장 후 재시도 (1회)

### 수동 처리 필요
- No transcript: 자막 없는 영상은 스킵
- Private video: 공개 상태 확인 필요
- Invalid JSON: 프롬프트 조정 필요
